# QuickShare Storage

This repository is used by the QuickShare Cloud college mini-project prototype to store small, non-sensitive demonstration files through the GitHub REST API.

## Public data warning

This repository is public. Treat every uploaded file as publicly accessible. Never upload personal, confidential, copyrighted-without-permission, or otherwise sensitive files.

Deleting a file from the latest branch does not guarantee removal from Git history. This repository is not a production temporary-file storage service.

## Limits

The QuickShare app enforces its own file-size, expiration, and download-limit policies. GitHub repository/API limits also apply.
